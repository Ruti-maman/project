# תיקיית demo

התיקייה הזו לא חלק מהאפליקציה עצמה — היא קיימת רק בשביל הדמו שרץ ב-GitHub Pages.

באופן רגיל האפליקציה מדברת עם ה-API האמיתי שכתוב ב-TypeScript ויושב ברפו הנפרד `helpdesk-api-main`
(Express + מסד נתונים), דרך `src/services/api.ts`.

ב-GitHub Pages מתארח רק קוד צד-לקוח — אין שרת שאפשר לפנות אליו. לכן בזמן ה-build הקובץ
`demo/api.demo.ts` מועתק **על גבי** `src/services/api.ts`. הוא מייצא בדיוק את אותו מופע axios,
עם אותם interceptors, אבל עם `adapter` משלו שעונה לכל הבקשות מתוך הדפדפן במקום מהרשת.

הנתונים נשמרים ב-`localStorage` תחת המפתח `helpdesk-demo-db`, כך שכל שינוי (פתיחת קריאה, תגובה,
שינוי סטטוס) שורד רענון של הדף. כדי לאפס את הדמו למצב ההתחלתי: `__resetDemo()` בקונסול.

שום קובץ אחר בפרויקט לא משתנה ולא יודע על קיום הדמו.
